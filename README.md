# 🎼 合唱練習プレイヤー

学校の合唱練習で使うことを想定した、スマートフォン対応の音源プレイヤーWebアプリです。
ソプラノ・アルト・男声・ピアノ伴奏などの音源を**個別の音量で重ねて同時再生**できます。
サーバーやログインは不要で、登録した音源・設定はすべて端末内（IndexedDB / localStorage）に保存されます。PWAとしてホーム画面に追加すれば、オフラインでも基本機能が使えます。

---

## 使い方（基本の流れ）

1. 「＋ 曲を追加」で曲名を入力する
2. 曲の詳細画面で「＋ 音源を追加」から音声ファイルを登録する（曲名・パート・音源名を設定）
3. 音源をタップ、または各音源の音量スライダーで自分のパートだけ・伴奏と一緒に、など好きな組み合わせで再生する
4. よく使う組み合わせは「プリセット」として保存すると次回からワンタップで呼び出せる
5. 気づいたことは「メモ」に時間と一緒に残しておく（メモをタップするとその位置に再生位置が移動）

再生位置は自動的に保存されるので、練習を中断してもアプリを開き直せば続きから再生できます（「最初から再生する」でリセットも可能）。

## 実装した機能一覧

### 曲・音源の管理
- 曲の追加・曲名編集・削除（削除前に確認ダイアログを表示）
- 音声ファイルの登録（MP3 / WAV / M4A / AAC / OGG / WebM に対応。非対応形式はわかりやすいエラーを表示）
- 音源ごとの曲名・音源名・パート（ソプラノ / アルト / 男声 / 全体 / ピアノ伴奏 / その他〈自由入力〉）の設定・編集
- 音源・曲の削除（確認ダイアログ付き）
- 曲・音源の並び替え（名前順・パート順・追加日時順、および音源はドラッグ＆ドロップによる手動並び替え）
- 曲名・音源名・パート名からの検索

### 再生
- 再生・一時停止・停止・シークバー・現在時間／総時間表示
- 音量調整・ミュート
- 10秒戻る／進む（大きなボタンで配置）、キーボードでは←→（5秒）・Shift+←→（10秒）、Spaceで再生/一時停止
- 再生速度変更（0.5x〜2x）
- 全体リピート、A-Bリピート（A/B地点はワンタップで設定・解除可能）
- 前回の再生位置を自動保存し、次回起動時に再開できる（「最初から再生する」も選択可）

### 複数音源の同時再生（このアプリの中心機能）
- Web Audio API（AudioContext + GainNode）を使い、トラックごとに独立した音量で同時再生
- 全トラックを同一のAudioContext時刻から再生開始することで、可能な限り再生位置のズレを防止
- 「ソロ」ボタンで自分のパートだけを即座に再生
- 「全体再生」「全ミュート」のクイック操作
- 音量の組み合わせを「プリセット」として保存・編集・削除し、ワンタップで呼び出し

### メモ
- 曲ごとにメモを保存（時間位置と関連付け可能）
- 時間付きメモをタップするとその位置へ再生位置が移動
- メモの編集・削除

### データ保存・バックアップ
- 音声データはIndexedDBに保存（大容量データをlocalStorageに保存しない設計）
- 設定・音量・再生速度・プリセット・テーマなどの軽量データはlocalStorageに保存
- 保存容量不足時にわかりやすいエラーメッセージを表示
- エクスポート（.zip形式：メタデータのJSON + 音声ファイルをまとめてバックアップ）
- インポート（エクスポートした.zipから曲・音源・メモ・プリセット・音声データを復元）

### PWA・UI
- manifest.json / Service Workerによるオフライン対応（アプリ本体をキャッシュし、ネットワークがなくても起動・再生が可能）
- ホーム画面への追加に対応
- スマートフォン優先のレスポンシブデザイン（PC・タブレットにも対応）、横画面にもある程度対応
- ダークモード／ライトモード（端末設定への追従、手動切り替えも可能）
- アクセシビリティ：主要ボタンへのaria-label、キーボード操作、フォーカス表示、音量・再生状態の視覚的表示（色だけに依存しない表示）

### エラー処理
JavaScriptの例外をそのまま表示せず、以下のようなケースをわかりやすい日本語メッセージに変換して通知します。
- 非対応の音声形式／音源の読み込み失敗
- IndexedDBの保存エラー・容量不足
- 不正なバックアップファイル
- Service Worker登録エラー（コンソールに記録し、アプリ自体は通常どおり動作）

## ファイル構成

```
/
├── index.html          … アプリ全体のHTML構造（画面・モーダル）
├── style.css            … デザインシステム（配色・タイポグラフィ・レイアウト・ダークモード）
├── app.js                … 画面遷移・CRUD・検索/並び替え・プリセット・メモ・インポート/エクスポート等の制御
├── db.js                 … IndexedDB / localStorage のアクセス層
├── audio.js              … Web Audio APIによる複数音源同時再生エンジン
├── player.js             … プレイヤーUI（再生ボタン・シークバー・速度・リピート等）の制御
├── manifest.json         … PWAマニフェスト
├── service-worker.js     … オフラインキャッシュ
├── icons/                … アプリアイコン（通常用・maskable用、192px・512px）
└── README.md             … このファイル
```

## 技術メモ・既知の制約

- 複数音源はすべて同一のAudioContext時刻から再生を開始することで同期させています。再生速度を変更した際は、音の高さ（ピッチ）が変化します（ブラウザの音声処理上の制約によるもので、ピッチを保ったまま速度のみを変えることは実装していません）。
- バックアップのエクスポート／インポート機能はJSZipライブラリ（CDN）を利用しています。初回利用時はオンライン環境である必要があります（一度読み込まれればService Workerによりキャッシュされ、以降はオフラインでも利用できます）。
- 音声ファイルは外部サーバーへ送信されません。バックアップの.zipファイルも端末内で生成され、ユーザー自身がダウンロード・保存します。
- 「ソロ」操作は他の音源の音量を0%にする一括操作です。元の音量バランスに戻したい場合は、プリセットとして保存しておくと簡単に呼び出せます。
